# ADHD-OS — Executive Function Operating System

## Overview
A state-aware behavioural architecture designed to externalise regulation functions impaired in ADHD. Not a productivity app — a digital scaffolding system that adjusts environmental architecture to accommodate executive function variability.

## Core Principles (from whitepaper)
- ADHD is a disorder of **performance, not knowledge** (Barkley, 1997)
- Internal executive functions are impaired → **external systems must replace them**
- State fluctuation (energy, focus, stress) is **normative**, not error
- Every system has a **novelty half-life** — build in flexibility
- Streak-based shame mechanics and variable reward manipulation are **exploitative** — avoid

## Four-Layer Architecture
1. **State Engine** — models dynamic internal states (energy, focus, stress, confidence, time perception)
2. **Behavioural Layer** — adapts task exposure based on current state
3. **Reflection Layer** — pattern analysis, plan review, blind spot detection
4. **Guardrails** — crisis safety, anti-shame mechanics, ethical safeguards

## Tool Evaluation Criteria (from ADHD-OS framework)
1. **Capture friction** — Can you add a task in <5 seconds?
2. **Today view** — Can you see ONLY today's tasks?
3. **Motivational design** — Does completing tasks feel rewarding?
4. **Graceful degradation** — What happens after 5 days of not opening?
5. **Workflow flexibility** — Can you switch views without migrating data?
6. **Integration depth** — Does it pull from existing work tools?
