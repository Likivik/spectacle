# Электронная подпись с Рутокен на NixOS

## Токен

Рутокен ЭЦП 3.0 3100 NFC Slim-A (ФСТЭК).

## КриптоПро CSP 5.0

### 1. Скачать дистрибутив

1. Зайти на https://cryptopro.ru/products/csp и нажать «Скачать»
2. Пройти регистрацию (если нет аккаунта) или войти
3. Выбрать раздел **КриптоПро CSP** → **5.0 R3** (на декабрь 2025) → **Linux (x64/amd64)** (файл вида `linux-amd64_deb.tgz`)
4. Скачать. Файл весит ~180 MB

### 2. Установка

Скопировать архив на машину и распаковать:

```bash
tar -xf linux-amd64_deb.tgz
cd linux-amd64_deb
```

**Установить минимальный набор пакетов через скрипт:**

```bash
sudo ./install.sh \
  cprocsp-rdr-pcsc \
  cprocsp-rdr-rutoken \
  cprocsp-rdr-cryptoki \
  cprocsp-pki-cades \
  cprocsp-pki-plugin \
  cprocsp-tools-gtk
```

Что каждый пакет даёт:

- `cprocsp-rdr-pcsc` — поддержка PC/SC смарт-карт (чит-токенов)
- `cprocsp-rdr-rutoken` — поддержка Рутокен через PC/SC
- `cprocsp-rdr-cryptoki` — PKCS#11 библиотека для Рутокен
- `cprocsp-pki-cades` — CADES COM-объекты (нужны для Saby, Diadoc)
- `cprocsp-pki-plugin` — Browser plug-in (Mozilla, Chromium)
- `cprocsp-tools-gtk` — графическая утилита «Инструменты КриптоПро»

**NB**: После установки перезагрузить сессию или выйти-зайти — чтобы подхватились группы пользователей (plugdev). Либо явно:

```bash
sudo usermod -aG plugdev $USER
```

### 3. Лицензия

Узнать серийник из УЦ (обычно приходит письмом от удостоверяющего центра, или встроен в сертификат):

```bash
# Если в сертификате есть встроенная лицензия, она применится автоматически
# при первом обращении к сертификату.

# Проверить статус лицензии:
/opt/cprocsp/sbin/amd64/cpconfig -license -view
```

Если лицензия **не активна** — CSP работает 90 дней в ознакомительном режиме, потом блокируется функция подписи. Актуальный таймер:

```bash
/opt/cprocsp/sbin/amd64/cpconfig -license -view | grep "Осталось дней"
```

Установить серийный номер вручную:

```bash
sudo /opt/cprocsp/sbin/amd64/cpconfig -license -set XXXXX-XXXXX-XXXXX-XXXXX-XXXXX
```

### 4. Проверка

Токен виден?

```bash
pkcs11-tool --module /opt/cprocsp/lib/amd64/librtpkcs11ecp.so --list-slots
```

Должен показать как минимум 1 слот — ключевой носитель (токен).

Контейнеры и сертификаты на токене:

```bash
/opt/cprocsp/bin/amd64/certmgr --list
```

Криптопровайдер работает:

```bash
/opt/cprocsp/bin/amd64/csptest -keys -verifycontext
```

Ожидается: `Test OK` или `[ErrorCode: 0x00000000]`.

Браузерный плагин виден Firefox:

```bash
ls -la /opt/cprocsp/lib/amd64/libnpcades.so
# должен существовать
```

Плагин также должен быть симлинкнут в каталог Mozilla плагинов:

```bash
ls -la /usr/lib/mozilla/plugins/libnpcades.so
# ожидается ссылка на /opt/cprocsp/lib/amd64/libnpcades.so
```

### 5. Особенности NixOS

На NixOS `/opt/cprocsp/lib/amd64` не добавляется в `ldconfig` при пересборке.
**Den aspect `cprocsp`** устанавливает `LD_LIBRARY_PATH` на этот путь.

Проверить, что подхватилось после `nh os switch`:

```bash
echo $LD_LIBRARY_PATH | grep cprocsp
```

Если пусто — перезайти в сессию (log out/in) или:

```bash
source /etc/profile
```

## Смена PIN-кодов токена

**Важно**: сменить PIN-коды перед использованием реальных сертификатов!

Дефолтные PIN-коды: пользователь `12345678`, администратор `87654321`.

Установить `pcsc-tools`, если ещё нет:

```bash
nix shell nixpkgs#pcsc-tools
```

**Сменить PIN пользователя:**

```bash
pkcs11-tool --module /opt/cprocsp/lib/amd64/librtpkcs11ecp.so \
  --login --pin 12345678 --change-pin
```

Ввести старый PIN (`12345678`) → новый PIN → подтвердить.

**Сменить PIN администратора:**

```bash
pkcs11-tool --module /opt/cprocsp/lib/amd64/librtpkcs11ecp.so \
  --login --pin 87654321 --change-pin --so-pin
```

**Проверить, что PIN сменились** — токен авторизуется с новым PIN:

```bash
pkcs11-tool --module /opt/cprocsp/lib/amd64/librtpkcs11ecp.so \
  --login --pin <новый_пин> --list-objects
```

### Если что-то пошло не так

**Плагин не виден в Firefox:**
```bash
# Переустановить только плагин
cd linux-amd64_deb
sudo ./install.sh cprocsp-pki-plugin

# Или вручную создать симлинк
sudo mkdir -p /usr/lib/mozilla/plugins
sudo ln -sf /opt/cprocsp/lib/amd64/libnpcades.so /usr/lib/mozilla/plugins/
```

**Токен не определяется в `pkcs11-tool`:**
```bash
# Перезапустить службу PC/SC
sudo systemctl restart pcscd

# Проверить логи
journalctl -u pcscd -n 20
```

**Контейнеры на токене не видны, хотя токен в списке слотов есть:**
Убедиться, что PIN пользователя — дефолтный (`12345678`) или тот, на который сменили.
Если PIN администратора меняли, а пользователя нет — контейнеры могут быть недоступны.
Сбросить PIN пользователя через PIN администратора:

```bash
pkcs11-tool --module /opt/cprocsp/lib/amd64/librtpkcs11ecp.so \
  --login --so-pin <admin_pin> --init-pin --new-pin <new_user_pin>
```

## Профиль Firefox

```bash
firefox -P
```

Создать профиль `gov-sign`. Цвет темы — оранжевый.

## Корневой сертификат Минцифры — только в профиль gov-sign

Скачать:

```bash
wget https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt
wget https://gu-st.ru/content/lending/russian_trusted_sub_ca_pem.crt
```

Установить:

```bash
# Найти директорию профиля
ls ~/.mozilla/firefox/*.gov-sign/

certutil -A -n "Russian Trusted Root CA" -t "CT,C,C" \
  -i russian_trusted_root_ca_pem.crt \
  -d sql:~/.mozilla/firefox/<profile>.gov-sign

certutil -A -n "Russian Trusted Sub CA" -t "CT,C,C" \
  -i russian_trusted_sub_ca_pem.crt \
  -d sql:~/.mozilla/firefox/<profile>.gov-sign
```

Проверка:

```bash
certutil -L -d sql:~/.mozilla/firefox/<profile>.gov-sign
```

## Расширения для gov-sign

Скачать и установить вручную через `about:addons` → шестерёнка → Install Add-on From File:

- **CryptoPro Extension for CAdES Browser plug-in** — cades plugin (ставится с КриптоПро, расширение отдельно)
- **Расширение для плагина Госуслуг** — IFCPlugin (скачать с gosuslugi.ru)
- **Kontur.Diadoc** — плагин с h.kontur.ru/plugin/linux

(В плане: заменить на declarative extension install через home-manager)

## Запуск

```bash
firefox -P gov-sign
```

## Управление pcscd (системная служба)

Аспект включает её через `services.pcscd.enable`. Вручную:

```bash
sudo systemctl start pcscd
sudo systemctl enable pcscd
sudo systemctl status pcscd
```
