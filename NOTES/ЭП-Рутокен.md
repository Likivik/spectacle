# Электронная подпись с Рутокен на NixOS

## Токен

Рутокен ЭЦП 3.0 3100 NFC Slim-A (ФСТЭК).

**Сменить PIN-коды перед использованием:**

```bash
# Установить pcsc-tools, если не установлен
nix shell nixpkgs#pcsc-tools

# Сменить PIN пользователя
pkcs11-tool --module /opt/cprocsp/lib/amd64/librtpkcs11ecp.so \
  --login --pin 12345678 --change-pin

# Сменить PIN администратора
pkcs11-tool --module /opt/cprocsp/lib/amd64/librtpkcs11ecp.so \
  --login --pin 87654321 --change-pin --so-pin
```

## КриптоПро CSP 5.0

Скачать с cryptopro.ru (регистрация). Установка:

```bash
tar -xf linux-amd64_deb.tgz
cd linux-amd64_deb
sudo ./install.sh cprocsp-rdr-pcsc cprocsp-rdr-rutoken cprocsp-rdr-cryptoki \
  cprocsp-pki-cades cprocsp-pki-plugin cprocsp-tools-gtk
```

Активация лицензии:

```bash
sudo /opt/cprocsp/sbin/amd64/cpconfig -license -set <серийный-номер>
```

Проверка:

```bash
# Токен виден?
pkcs11-tool --module /opt/cprocsp/lib/amd64/librtpkcs11ecp.so --list-slots

# Контейнеры и сертификаты?
/opt/cprocsp/bin/amd64/certmgr --list

# Криптопровайдер?
/opt/cprocsp/bin/amd64/csptest -keys -verifycontext
```

## Профиль Firefox

```bash
firefox -P
```

Создать профиль `gov-sign`. Цвет темы — оранжевый.

## Корневой сертификат Минцифры — только в профиль gov-sign

Скачать:

```bash
wget https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt
wget https://gu-st.ru/content/lending/russian_trusted_sub_ca_pem.crt
```

Установить:

```bash
# Найти директорию профиля
ls ~/.mozilla/firefox/*.gov-sign/

certutil -A -n "Russian Trusted Root CA" -t "CT,C,C" \
  -i russian_trusted_root_ca_pem.crt \
  -d sql:~/.mozilla/firefox/<profile>.gov-sign

certutil -A -n "Russian Trusted Sub CA" -t "CT,C,C" \
  -i russian_trusted_sub_ca_pem.crt \
  -d sql:~/.mozilla/firefox/<profile>.gov-sign
```

Проверка:

```bash
certutil -L -d sql:~/.mozilla/firefox/<profile>.gov-sign
```

## Расширения для gov-sign

Скачать и установить вручную через `about:addons` → шестерёнка → Install Add-on From File:

- **CryptoPro Extension for CAdES Browser plug-in** — cades plugin (ставится с КриптоПро, расширение отдельно)
- **Расширение для плагина Госуслуг** — IFCPlugin (скачать с gosuslugi.ru)
- **Kontur.Diadoc** — плагин с h.kontur.ru/plugin/linux

(В плане: заменить на declarative extension install через home-manager)

firefox -P gov-sign
